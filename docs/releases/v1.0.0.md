# Teramic 1.0.0

Das erste GitHub-Release enthält das Voxelspiel, den Dedicated Server und den Gebäudeeditor. Jedes Plattformpaket enthält alle drei Programme, Spielinhalte und Standardkonfigurationen.

- Erd-, Wasser- und Dunkeldrachen verteidigen ihre Nester mit eigenen Angriffen und Kampfthemen. Auch Sandwürmer und Spinnen nutzen artspezifische Angriffe.
- Salz-, Tropfstein-, Eis- und Lush-Höhlen lassen sich im Spiel mit `/locate biome` finden. Tageslicht fällt durch reale Öffnungen. Neue Welten erhalten die überarbeiteten Höhlenformen.
- Wasser, Galle und Teer fließen im Terrain. Teer schließt auf bedeckten Pfaden bündig mit benachbarten Blöcken ab.
- Diese Ausgabe verbessert Mobbewegungen und Angriffsabläufe, die Sicht in Drachenhöhlen und die Reichweite leuchtender Props und Blöcke.

Zum Spielen das vollständige Archiv für Linux (x86-64), macOS (Apple Silicon) oder Windows (x86-64) in einen beschreibbaren Ordner entpacken und `terra-client` starten. Die mitgelieferte README erklärt Serverstart, Verbindung und Editor. Die SHA-256-Prüfsummen stehen in `SHA256SUMS.txt`.
